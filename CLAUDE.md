## Skills

Read the relevant skill in `.claude/skills/` before writing code. Project skills set the conventions and win over the third-party ones where they differ.

- Project: `new-component`, `gsap`, `styling`
- GSAP (official, GreenSock): `gsap-core`, `gsap-react`, `gsap-scrolltrigger`, `gsap-timeline`, `gsap-plugins`, `gsap-performance`
- React and UI (Vercel, optional, installed locally per README): `vercel-react-best-practices`, `web-design-guidelines`

The project is plain JavaScript. Translate any TypeScript in skill examples.
Third-party skills are pinned in `skills-lock.json`. Update them with `npx skills update -p`.
